# Skill Flask

Персональный трекер развития навыков. Выполненные действия приносят очки, очки заполняют колбы, каждая заполненная колба — новый уровень. Требования: `Skill Flask — требования к персональному MVP v0.2`.

Приложение мобильное: Telegram Mini App и мобильный браузер, дальше — нативное приложение. Десктоп не поддерживается специально.

## Что умеет первый срез

Цепочка «навык → действие → очки → колба → веха → завершение» (раздел 13 требований):

- создание навыка с подписями «сейчас → цель», вехой (по умолчанию 10 колб) и ёмкостью колб;
- действия типа «выполнено / нет» с фиксированными баллами;
- ручная отметка выполнения, в том числе задним числом;
- перенос остатка очков в следующую колбу, несколько колб за одно выполнение;
- достижение вехи и выбор «Завершить» / «Продолжить»;
- история выполнений с состоянием колбы после каждой операции;
- редактирование и полное удаление навыка.

Ачивки и «Список дел» пока заглушки.

## Стек

- React + TypeScript + Vite;
- IndexedDB через Dexie — данные хранятся локально на устройстве;
- Vitest + fake-indexeddb для тестов.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, доступен и с телефона в той же сети
npm test           # unit- и интеграционные тесты
npm run build      # сборка в dist/
```

## Структура

```
src/domain/     чистая бизнес-логика без хранилища и UI
  progression.ts  расчёт уровня по журналу очков и ёмкостям колб
  milestone.ts    правила вехи и завершения навыка
src/data/       схема IndexedDB (версия Dexie = версия схемы)
src/services/   сценарии (создать навык, отметить выполнение…) и read-модели для UI
src/ui/         экраны и компоненты
src/telegram.ts обёртка над Telegram Mini App API (вне Telegram — no-op)
```

Ключевые решения:

- Прогресс не хранится одним числом: это сумма операций `PointTransaction`, уровень всегда пересчитывается из журнала.
- `StepCompletion` хранит снимок настроек шага, поэтому изменение шаблона не меняет прошлое.
- Ёмкость колбы: сначала «свои значения», затем линейный рост `база + прирост × (n − 1)` (по умолчанию 100, 150, 200…).
- Завершённый навык доступен только для чтения. Если активный навык потерял очки ниже вехи, веха снова становится недостигнутой.

## Telegram Mini App

1. Включить GitHub Pages: *Settings → Pages → Source: GitHub Actions*. После пуша в `main` workflow `CI` опубликует сборку.
2. В [@BotFather](https://t.me/BotFather): `/newbot`, затем `/newapp` (или *Bot Settings → Menu Button*) и указать URL страницы.

Цвета приложения берутся из темы Telegram, используются нативная кнопка «Назад», подтверждения и вибро-отклик.

Данные хранятся в IndexedDB WebView-а Telegram на конкретном устройстве; синхронизации между устройствами пока нет.
