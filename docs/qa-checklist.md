# QA-чеклист: устройства и платформа

Ручные проверки, которые не покрывают jsdom-тесты и скриншоты. Прогоняются перед релизом на
четырёх конфигурациях. Отметка — дата и устройство в ячейке.

## Матрица устройств

| # | Конфигурация | Зачем |
|---|---|---|
| A | Telegram iOS (актуальный клиент, iPhone с «чёлкой») | safe-area, WKWebView, клавиатура, вибро |
| B | Telegram Android на слабом телефоне (2–3 ГБ ОЗУ, Android WebView ≤ 110) | производительность, fallback `color-mix`, `navigator.vibrate` |
| C | Safari iOS (мобильный браузер, вкладка) | `env(safe-area-inset-*)`, зум, `100dvh`, `visualViewport` |
| D | Chrome Android (мобильный браузер) | `interactive-widget=resizes-content`, вибро, тёмная тема системы |

## Проверки

| Проверка | Как | A | B | C | D |
|---|---|---|---|---|---|
| Клавиатура в листе | Открыть лист с полем (styleguide → «Лист»), нажать в поле: поле видно, футер листа поднят над клавиатурой, страница за листом не прокрутилась | | | | |
| Safe areas | Заголовок экрана не под статус-баром / шапкой Telegram; таббар и футер над home-индикатором; лист учитывает нижний отступ | | | | |
| Fallback `color-mix` | На старом WebView (B, без `color-mix`) срабатывают литеральные значения из `@supports`-обхода: вторичный текст, мягкий акцент, фон чипов/скелетона, красная кнопка и жидкость видны, ничего не прозрачное и не чёрное | | | | |
| Вибро-отклик | Отметка выполнения (успех), заполнение колбы (тяжёлый + успех), веха (двойной успех), ошибка; выключатель в «Настройках» (пакет 4) глушит всё | | | | |
| Кнопка «Назад» закрывает лист | Открыть лист → нативная «Назад» (Telegram) / системная «Назад» (Android) / свайп «назад» (iOS): закрывается лист, экран остаётся; второй «Назад» уходит с экрана | | | | |
| Нет белой вспышки на тёмной теме | Холодный старт и перезагрузка в тёмной теме Telegram и в тёмной системе: фон сразу тёмный, `theme-color` совпадает | | | | |
| 130 % системный шрифт | Включить крупный шрифт в системе: заголовки не режутся, строки списка растут, футер не перекрывает контент, цифра колбы влезает на 320 px | | | | |
| MainButton | Формы навыка/действия и «Добавить действие»: нативная кнопка вместо HTML-футера, неактивна пока нельзя отправить, прогресс во время сохранения, скрыта после ухода с экрана | | — | — | — |
| SecondaryButton (7.10+) | В Telegram ≥ 7.10 вторичная кнопка нативная; ниже — HTML-кнопка в футере | | — | — | — |
| Смена темы на лету | Переключить тему Telegram при открытом приложении: цвета, шапка и нижняя панель меняются без перезагрузки; аккцент #222 → жидкость циановая | | | — | — |
| Подтверждение закрытия | Начать заполнять форму, потянуть приложение вниз / закрыть: Telegram спрашивает; после сохранения — нет | | | — | — |
| Свайп листа | Свайп вниз за ручку/заголовок и за тело при scrollTop = 0 закрывает; свайп вверх — сопротивление; быстрый флик закрывает даже с малым смещением | | | | |
| Тост | Тост над таббаром на корневых экранах, над safe-area на вложенных; свайп вниз/тап убирает; «Отменить» кликается одним пальцем (44 px) | | | | |
| Уменьшить движение | Системная настройка: лист появляется без пружины (только прозрачность), скелетон без шиммера, полосы без анимации | | | | |
| Облачная копия | В Telegram отметить действие, свернуть приложение: в «Настройках» статус «Сохранено сегодня в …»; «Очистить кэш» Telegram (или переустановка) → при запуске «Найдена резервная копия…» → «Восстановить» возвращает навыки и историю; на втором телефоне с тем же аккаунтом — то же | | | — | — |
| Файл копии | «Скачать файл»: в браузере сохраняется `skill-flask-ДАТА.json`; в Telegram iOS/Android открывается «Поделиться» с файлом (без blob-ссылок), иначе текст копируется в буфер; «Загрузить из файла…» выбирает файл, показывает «Навыков: … · выполнений: …» и заменяет данные | | | | |
| Зум | Двойной тап / щипок увеличивает страницу (зум не запрещён) | — | — | | |
| Колба: заполнение | Навык с ёмкостью 10 и действием на 5: отметить дважды. «+5» улетает из кнопки в колбу, жидкость поднимается до края, капли переливаются, сильная вибрация в момент перелива, колба сливается и наполняется заново, пилюля «Колба 2», цифра прокручивается 1 → 2. На слабом телефоне (B) без рывков; оверлея нет, список действий кликается всё время | | | | |
| Колба: пауза и «меньше движения» | Свернуть приложение во время волны и вернуться — волна продолжает с того же места, пока скрыто — не тратит кадры (Performance в `chrome://inspect`); «Меньше анимации» — только короткое проявление, без полёта очков и перелива | | | | |
| Лист вехи | Отметка, достигающая вехи: колба доигрывает заполнение, затем лист «Веха достигнута» с вибро; «Решу позже» закрывает, выбор остаётся на карточке вехи; «Назад» Telegram закрывает лист | | | | |
| TopCard | «Задним числом» с заполнением колбы: при возврате сверху карточка «Колба заполнена», уходит сама через 3,5 с, смахивается вверх; не перекрывает нативную шапку Telegram | | | | |
| Карточка ачивки | Новый навык (первый) и первая отметка: под шапкой карточка «Новая ачивка» с поворотом медали и нажатием-вибро; уходит через 3,5 с, смахивается вверх, тап открывает «Ачивки» с подсвеченной плиткой; во время листа вехи не появляется, после «Решу позже» — появляется; три и больше за одну отметку — одна карточка «… и ещё N ачивки»; при повторном запуске приложения ничего не показывается | | | | |
| Вкладка «Ачивки» | Точка на вкладке после новой ачивки, гаснет примерно через секунду на вкладке; лестницы раскрываются, плитки и ступени открывают лист; «Лучшая серия» показывает рекорд, а не текущую серию; на 320 px и при 130 % шрифте ничего не выходит за экран | | | | |
